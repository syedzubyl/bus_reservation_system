# Bus Reservation System - Phase 1

## Project Overview
This is a basic Spring Boot application for a Bus Reservation System, built progressively as part of a Junior Java Backend Developer portfolio.

## Technology Stack
- Java 17
- Spring Boot 3.2.x
- Maven

## Project Structure
Standard Maven structure with `src/main/java` and `src/main/resources`.

## How to Run
Run the main class `BusReservationApplication.java` from your IDE, or use Maven:
`mvn spring-boot:run`
